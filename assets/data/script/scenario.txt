// =========================================================================
// 비주얼노벨 샘플 시나리오.
// 문법:
//   /scene <sceneName>           : 새 장면.
//   /branch <branchName>         : 새 선택지 분기.
//   /speaker <name>              : 화자 이름. (이후 /say 에 적용)
//   /character <preset|none>     : 캐릭터 실루엣 (swordsman / elder / taoist / none).
//   /time <day|night|sunset>     : 시간대 (배경 프리셋).
//   /say <text>                  : 화자의 대사. (\n 으로 줄바꿈)
//   /narration <text>            : 화자 없는 나레이션.
//   /option <라벨> -> <nextScene>: 선택지 항목.
//   //                           : 줄 주석.
// =========================================================================


// -------------------------------------------------------------------------
// 인트로.
// -------------------------------------------------------------------------
/scene intro
/time sunset

/character none
/narration 오래된 산의 능선이 황혼에 물든다.\n수련자 한두백, 그는 마침내 산문 앞에 섰다.

/character swordsman
/speaker 한두백
/say 이 산… 수년의 발걸음이 마침내 닿았구나.

/character elder
/speaker 검종 장로
/say 그대는 누구인가. 어찌하여 검종의 산문을 두드리는가?

/character swordsman
/speaker 한두백
/say 수선의 길에 들고자 합니다. 가르침을 청합니다, 장로님.

/character elder
/speaker 검종 장로
/say 흠… 의지는 굳어 보인다.\n허나 입문에는 시험이 있어야 하는 법.

/say 내 한 가지 물으마. 그대는 어떤 마음으로 검을 잡으려 하는가?


// -------------------------------------------------------------------------
// 첫 선택지.
// -------------------------------------------------------------------------
/branch after_intro
/option 사람을 지키기 위한 신뢰의 검입니다. -> path_trust
/option 아직은 모릅니다. 다만 약함을 견딜 수 없습니다. -> path_doubt


// -------------------------------------------------------------------------
// 신뢰의 길.
// -------------------------------------------------------------------------
/scene path_trust
/time night

/character swordsman
/speaker 한두백
/say 검은 사람을 지키기 위함입니다.\n저의 검은 신뢰의 검이 될 것입니다.

/character elder
/speaker 검종 장로
/say 신뢰라… 가벼이 입에 담을 말이 아니다.\n허나 그 답은 검종의 길과 통한다.

/say 그대를 받겠다. 단, 약조하라.\n네 검이 어두운 마음에 흔들리지 아니할 것을.

/character swordsman
/speaker 한두백
/say 삼가 그 약조를, 제 검에 새기겠습니다.


// -------------------------------------------------------------------------
// 의심의 길.
// -------------------------------------------------------------------------
/scene path_doubt
/time night

/character swordsman
/speaker 한두백
/say 솔직히 말하면, 아직 잘 모르겠습니다.\n다만 약한 채로 이대로 머물 수는 없습니다.

/character elder
/speaker 검종 장로
/say 솔직함은 첫 걸음의 자질이다.\n허나 의심은 검을 무디게 만든다.

/say 그대를 받되, 한 가지를 더 시험하리라.\n네 의심을 검의 끝으로 옮길 수 있을 때, 그때 비로소 입문이다.

/character swordsman
/speaker 한두백
/say 그 시험… 받겠습니다.


// -------------------------------------------------------------------------
// 에필로그.
// -------------------------------------------------------------------------
/scene epilogue
/time night
/character none
/speaker
/narration 산문이 열렸다. 멀리서 풍경의 소리가 흩어진다.

/narration 한두백의 수선전, 이제 막 첫 장을 닫는다.\n\n— 끝 —
